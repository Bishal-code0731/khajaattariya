# Khaja Attariya 🍽️

> Delicious food to your doorstep.

A role-based food delivery platform built for Attariya, Kailali — connecting local restaurants with customers through three distinct user flows: **customer ordering**, **restaurant order management**, and **rider delivery tracking**.

## Features
- **Customer app** — browse restaurants, place orders, track delivery in real time
- **Restaurant app** — manage incoming orders, update menu/availability
- **Rider app** — accept deliveries, update order status, live location tracking
- Role-based auth and routing across all three flows

## Tech Stack
- **Frontend** — Flutter (Android, iOS, Web)
- **Backend** — Firebase + Supabase
- **State Management** — Riverpod
- **Navigation** — go_router
- **Architecture** — Clean Architecture + MVVM

## Status
🚧 Under active development — core ordering flow functional, backend migration in progress.

## What I learned building this
Building three role-based flows in one codebase pushed me to get serious about clean state separation with Riverpod and structuring navigation so each role only sees what it should. It's also been my hands-on introduction to combining Firebase and Supabase in the same project.
